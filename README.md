# sensorithm

Simulate an IR sensor for rhythm games using a camera. Communicates with the game through the [Brokenithm](https://github.com/tindy2013/Brokenithm-Android-Server) shared buffer.

## Installation

Make sure you have [Brokenithm server](https://github.com/tindy2013/Brokenithm-Android-Server) installed and configured alongside your game files.

* **Server**: [`sensorithm-server.exe`](https://github.com/michioxd/sensorithm/releases/latest/download/sensorithm-server.exe) - Windows 64-bit only. The `.pdb` file is optional and only needed for debugging.
* **Client**: [`app-release.apk`](https://github.com/michioxd/sensorithm/releases/latest/download/app-release.apk) - Android 5.0 or higher.
